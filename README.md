# 수학 십자말

초등학생용 사칙연산 연습 퍼즐입니다. 숫자 칸 네 개를 가로로 읽어도 세로로 읽어도 식이 성립하도록 빈칸을 채웁니다.

**웹에서 바로 풀기 → https://number-grid-quiz.vercel.app**

```
   □   ×   3   =  18
   +       −
   4   +   □   =   5
   =       =
  10       2
```

위 문제의 답은 왼쪽 위가 6, 오른쪽 아래가 1입니다.

- 가로 첫째 줄 `6 × 3 = 18`
- 가로 둘째 줄 `4 + 1 = 5`
- 세로 첫째 줄 `6 + 4 = 10`
- 세로 둘째 줄 `3 − 1 = 2`

## 실행 방법

두 가지 중 편한 쪽을 쓰면 됩니다.

- **파일로 열기** — `quiz.html`을 더블클릭합니다. 설치도, 인터넷 연결도 필요 없습니다.
- **웹 주소로 열기** — https://number-grid-quiz.vercel.app 에 접속합니다. 휴대폰이나 태블릿에서 링크만 보내면 바로 풀 수 있습니다.

## 푸는 방법

1. 시작 화면에서 난이도를 고릅니다.
2. 노란 빈칸을 눌러 숫자를 입력합니다. **Enter** 또는 **Tab**으로 다음 빈칸으로 넘어갑니다.
3. 다 채우고 **확인**을 누릅니다.
   - 맞은 칸은 초록색, 틀린 칸은 빨간색으로 표시됩니다.
   - 틀린 칸이 들어간 가로·세로 식의 결과에도 빨간 표시가 붙어, 어느 줄을 다시 봐야 하는지 알 수 있습니다.
   - 틀려도 계속 고쳐서 다시 확인할 수 있습니다.
4. 네 식이 모두 맞으면 완성 화면이 나옵니다. **새 문제**를 누르면 다음 문제로, **난이도 바꾸기**를 누르면 시작 화면으로 돌아갑니다.

풀이 도중에는 합이나 곱을 자동으로 알려주지 않습니다. 직접 계산해 보게 하려는 의도입니다.

## 난이도

| 난이도 | 숫자 범위 | 빈칸 수 |
| --- | --- | --- |
| 쉬움 | 1~9 | 2개 |
| 보통 | 1~12 | 3개 |
| 어려움 | 1~20 | 3개 |

세 난이도 모두 덧셈·뺄셈·곱셈·나눗셈이 함께 나옵니다.

## 문제가 만들어지는 규칙

문제는 미리 저장해 둔 것이 아니라 열 때마다 새로 만들어집니다. 다음 세 가지를 항상 지킵니다.

- **나눗셈은 딱 나누어떨어질 때만** 씁니다. 나머지나 소수가 나오는 문제는 만들어지지 않습니다.
- **뺄셈은 결과가 0보다 클 때만** 씁니다. 음수가 나오는 문제는 만들어지지 않습니다.
- **답은 반드시 하나뿐입니다.** 빈칸에 들어갈 수 있는 모든 숫자 조합을 실제로 대입해 보고, 답이 하나로 정해지는 문제만 화면에 내보냅니다.

나눗셈은 나누어떨어지는 수를 만나야만 쓸 수 있어 그냥 두면 거의 나오지 않습니다. 그래서 나눗셈이 들어간 문제를 우선해서 찾도록 만들었고, 그 결과 **모든 문제에 나눗셈이 최소 한 번** 들어갑니다. 네 기호의 실제 비율은 대략 `+` 27%, `−` 19%, `×` 24%, `÷` 30%입니다.

## 고치는 방법

### 난이도 바꾸기

`quiz.html`의 283번째 줄 근처를 고칩니다.

```js
var LEVELS = {
  easy:   { min: 1, max: 9,  holes: 2 },
  normal: { min: 1, max: 12, holes: 3 },
  hard:   { min: 1, max: 20, holes: 3 }
};
```

- `min`, `max` — 칸에 들어가는 숫자의 범위
- `holes` — 빈칸 개수 (2 또는 3). 4로 하면 답이 하나로 정해지지 않을 수 있으니 3까지만 쓰세요.

### 연산 기호 비율 바꾸기

`pickOp` 함수에서 기호를 몇 번 넣느냐가 곧 뽑힐 확률입니다. 예를 들어 나눗셈을 줄이고 싶으면 `'÷'`를 적게 넣으면 됩니다.

```js
function pickOp(x, y){
  var pool = ['+', '×'];
  if (x - y >= 1) pool.push('−', '−', '−');
  if (y > 1 && x % y === 0) pool.push('÷', '÷', '÷', '÷', '÷', '÷');
  return pool[rand(0, pool.length - 1)];
}
```

### 색과 글씨 바꾸기

파일 위쪽 `:root` 안의 값들입니다.

```css
--paper:#FDFCF7;                  /* 종이 바탕색 */
--grid:#DCE6EF;                   /* 배경 모눈 선 */
--ink:#1F3A5F;                    /* 글씨와 칸 테두리 */
--pencil:#6B7A8F;                 /* 계산 결과 같은 흐린 글씨 */
--correct:#1E8E5A;                /* 맞았을 때 초록 */
--wrong:#D64550;                  /* 틀렸을 때 빨강 */
--marker:#FFD642;                 /* 커서가 있는 칸의 노랑 */
--cell:28px;                      /* 배경 모눈 한 칸의 간격 */
--cs:clamp(46px,13vw,70px);       /* 문제 칸 하나의 크기 */
```

글씨체는 인터넷이 연결돼 있으면 둥근 한글 서체(Jua)를 쓰고, 연결이 없으면 맑은 고딕으로 자동 대체됩니다.

## API 키 관리

`api.md`에 OpenAI API 키가 들어 있습니다. 이 파일은 다음 두 가지로 보호됩니다.

- **배포 폴더에 물리적으로 없습니다.** 웹에 올라가는 것은 `number-grid-quiz\` 폴더뿐이고, `api.md`는 그 안에 들어가지 않습니다.
- **`.vercelignore`와 `.gitignore`** 에 `api.md`, `*.key`, `.env*`가 등록돼 있습니다. 실수로 폴더째 배포하거나 git에 올려도 키는 빠집니다.

배포된 사이트에서 `/api.md`로 접근하면 404가 반환되는 것을 확인했습니다.

> **주의:** 이 키는 만들 때 대화창에 평문으로 노출된 적이 있습니다. 실제로 사용하실 예정이라면 OpenAI 대시보드에서 기존 키를 폐기하고 새로 발급받으시길 권합니다.

## 만들어진 과정

이 퍼즐은 세 번 형태가 바뀌었습니다. 처음에는 `3 + □ = 7` 형태의 계산식 빈칸 채우기였고, 그다음 가로세로 합을 맞추는 표였다가, 최종적으로 지금의 십자말 형태가 되었습니다. 각 단계마다 난이도별로 수백 문제를 자동 생성해 식이 성립하는지, 답이 하나뿐인지, 나눗셈이 나누어떨어지는지를 검사했습니다. 현재 버전은 **450문제 검사에서 오류 0건**입니다.
